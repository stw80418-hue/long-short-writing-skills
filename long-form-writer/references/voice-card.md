# 共用語氣參考卡格式 v1

長文與短文共用同一份品牌資料檔 `voice-card.md`。此檔是空白格式說明，不是任何人的實際語氣設定。不得把尚未提供的作者偏好補成既定規則。

```markdown
# 品牌語氣參考卡
格式版本：voice-card/v1
品牌／作者：待確認
更新日期：待確認
樣本範圍：待確認（文章數、長短文類型、平台）

| 欄位 | 寫作參考 | 依據／原文短例 | 狀態 |
| --- | --- | --- | --- |
| 讀者距離 | 待確認 | 未提供 | 待確認 |
| 句子長度 | 待確認 | 未提供 | 待確認 |
| 常用詞 | 待確認 | 未提供 | 待確認 |
| 不用的詞 | 待確認 | 未提供 | 待確認 |
| 開場習慣 | 待確認 | 未提供 | 待確認 |
| 轉折習慣 | 待確認 | 未提供 | 待確認 |
| 收尾習慣 | 待確認 | 未提供 | 待確認 |
| CTA 習慣 | 待確認 | 未提供 | 待確認 |
| AI 味禁用句型 | 待確認 | 未提供 | 待確認 |

## 長短文差異
- 短文節奏與斷句：待確認
- 長文段落、論述與案例展開：待確認

## 保留與校正
- 個人特色／幽默／不可磨平處：待確認
- 使用者回饋與修正：尚無
- 尚待確認：
```

狀態限「已確認」（使用者明確指定或認可）、「暫定」（樣本觀察）、「待確認」（缺乏依據）。沒出現在樣本中的詞不等於作者禁止使用；AI 味禁用句型不能自動套用一長串禁詞，須標明是作者偏好或暫定編輯建議。少量樣本不能推斷長期習慣。

同品牌只維護一份實際參考卡。先讀使用者指定路徑或任務卡的「語氣參考」；同對話已有卡就直接沿用。不同品牌資料不能混用；若有多份候選且無法判斷，只詢問要用哪份，不全磁碟搜尋。舊格式可對應成此格式，不要求重新提供文章。短文已有的口吻可沿用到長文，沒有長文範例的結構習慣仍標待確認，不阻擋起草。

使用者要求保存時，優先使用指定路徑；否則可存於當前內容專案的 `voice-card.md`，回報完整路徑。寫入前讀取既有檔案，保留無關欄位與已確認偏好，不覆寫成另一品牌。未保存時明說只在本次對話沿用。此私人資料檔不放入技能通用規則或公開發布包；參考卡的保存或讀取不代表模型被重新訓練。

## 儲存觸發語句

使用者直接要求「將語氣存到 skill 中」「請幫我將語氣存到 skill 中」「把語氣存進技能」或意思相同的儲存請求時，視為啟動共用語氣卡儲存流程，不是把私人語氣寫進 SKILL.md 或覆寫本格式範本。僅在文章、引言或教學範例出現這句話時不觸發；使用者要求設定觸發語句時，只更新規則，不順便保存個人語氣。

1. 優先使用本次已整理的語氣卡與使用者回饋；只有文章範例時，依固定格式整理，樣本推論標「暫定」。沒有可用樣本或語氣資料時，先請使用者提供，不建立假裝已學會的空卡。
2. 沿用使用者指定的檔案位置，或任務卡／本次對話已確認的同品牌語氣卡路徑；都沒有時，存到當前內容專案根目錄的 `voice-card.md`。沒有明確的內容專案位置，或目前工作目錄是技能原始碼／公開發布資料夾時，先詢問私人儲存位置，不自動存入發布包。
3. 既有檔案先讀取再合併，保留已確認偏好與無關欄位；品牌衝突才詢問，不另建長文版與短文版兩份資料。
4. 完成寫入後重新讀取，確認內容與位置正確，回報可點擊的完整路徑。寫入失敗如實說明，不宣稱已儲存。將該路徑放入當前任務卡的「語氣參考」，後續長短文共用。
5. 告知跨對話使用時仍須提供檔案或指定路徑；不宣稱永久記憶、自動跨專案載入，也不自動提交或推送到 GitHub。
