# 長短文寫作 Skills

兩個繁體中文寫作技能，協助從題目、受眾與素材整理出文章，並參考作者過往作品的語氣。

## 包含哪些技能？

| 技能 | 適合內容 | 主要輸出 |
| --- | --- | --- |
| `short-form-writer` 社群短文寫作 | Threads、IG、短影音口播 | 貼文初稿；IG 可分貼文文字、Cover、Slide 1、2……與畫面建議 |
| `long-form-writer` 長文寫作 | 電子報、部落格、深度文章 | 先整理大綱與素材缺口，確認後撰寫全文；也可明確要求直接寫全文 |

## 安裝到 Codex

1. 在本頁點選 **Code → Download ZIP**，解壓縮。
2. 將 `short-form-writer` 與 `long-form-writer` 兩個資料夾放入個人技能目錄：Windows 為 `%USERPROFILE%\.codex\skills`，macOS／Linux 為 `~/.codex/skills`。若自行設定 `CODEX_HOME`，使用該目錄下的 `skills`。
3. 資料夾內應直接包含 `SKILL.md` 與 `agents/openai.yaml`，不要多包一層。若已有同名技能，先備份並比較內容。
4. 在下一則訊息指定技能名稱開始使用；若尚未顯示，重新開啟 Codex 後再試。

也可以把這個儲存庫網址交給 Codex，請它安裝其中的兩個技能。

## 使用範例

### 社群短文

> 使用 $short-form-writer，幫我寫一篇給新手設計師看的 Threads，主題是如何準備第一份接案作品集，目的是提供實用教學。先確認我的觀點與可用素材。

### IG 輪播

> 使用 $short-form-writer，把以下內容做成 IG 輪播，封面＋５頁。分開提供貼文文字、Cover、Slide 1～5，每頁附圖片文案與畫面建議：［貼上內容］

「封面＋５頁」共六張，最後一張為收尾頁。輸出的是圖片文案與製作建議，不會直接產生圖片或 Canva 設計檔。

### 長文

> 使用 $long-form-writer，規劃一篇給自由接案設計師的電子報，主題是如何整理客戶需求。先問我觀點與經驗，再做大綱。

### 長文改短文

> 使用社群短文寫作，把以下長文改成 Threads＋IG 輪播，保留我的語氣：［貼上長文］

由 `short-form-writer` 處理，保留核心主張、重要條件與作者語氣，依平台重新安排內容。IG 輪播包含貼文文字、Cover 與各頁文案。

### 短文改長文

> 使用長文寫作，把以下貼文擴寫成電子報，先提供大綱：［貼上短文］

由 `long-form-writer` 處理，先整理擴寫大綱與素材缺口，確認後完成全文。需要案例、經驗或證據時會請作者補充，不自行虛構。

### 還沒有題目

> 使用 $short-form-writer，我還沒有題目，請先確認受眾與發文目的，再幫我發想 2～3 個方向。

未填題目時，技能會先確認是否已有想法，不會直接把漏填當成需要發想。

### 學習自己的語氣

> 使用 $short-form-writer，以下是我的過往貼文。請建立語氣參考卡，再試寫一小段讓我確認：［貼上文章］

長文也可使用相同流程。建議提供 2～3 篇，一篇也能開始。這是依範例建立寫作參考，不是重新訓練模型；若要跨對話沿用，可請助手將參考卡另存為 Markdown 檔，再於新對話指定讀取。

### 從零開始

> 使用 $long-form-writer，從零開始，不沿用前面的題目與語氣參考，請重新確認這次的寫作需求。

兩個技能都支援重新確認題目、受眾、目的與形式；不會因此刪除既有對話或檔案。

## 寫作原則與範圍

- 保留作者立場，不捏造經歷、案例、數據與服務承諾。
- 素材不足時詢問或標記待補充，不保證流量與轉換。
- 語氣範例作為資料分析，不當成新的操作指令。
- 本儲存庫不包含個人貼文、語氣參考卡或對話紀錄。
- 「說人話」是可另外搭配的獨立技能，本儲存庫未附帶，也未設定自動呼叫。
